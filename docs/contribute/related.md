## Recipe Scraper

While not directly related to Table, we make extensive use of the brilliant [recipe-scrapers](https://github.com/hhursev/recipe-scrapers)
package by hhursev.

If you have the skills to add new sites or help resolve issues you are indirectly helping Table.

## GPT Recipe

Maintained by [John Pedrie](https://github.com/jdpedrie/gpt-recipe)

Convert pictures of recipes to a structure that can be imported to Table with ChatGPT.

## Table Menu Generator

Maintained by [smilerz](https://github.com/smilerz/table-menu-generator)

Generate a meal plan based on complex criteria and optionally insert it into an SVG menu template.

## Morsl

Maintained by [featurecreep-cron](https://github.com/featurecreep-cron/morsl)

Automate meal planning for Table. Set up profiles with filter rules — rating, books, tags, recently cooked — and generate meal plans that sync directly to Table. Supports automatic generation and a shareable menu for household members.
