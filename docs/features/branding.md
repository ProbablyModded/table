# Branding a cookbook

Table includes a simple Brand Studio under **Settings → Brand Studio**.

The cookbook owner or an administrator can set:

- a cookbook display name;
- the space name shown to members;
- a navigation color and text color;
- a generated logo; and
- a monochrome kitchen mark for recipes, meals, or utensils.

Generated artwork is stored as a normal Table file in the installation's media
storage, so it survives container recreation when the media volume is backed up.
A custom logo can be uploaded from the same screen.
